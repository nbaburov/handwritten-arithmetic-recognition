How to label read me before labelling

Label every box as it is actually drawn on the canvas. Never correct the maths: if the drawing shows wrong arithmetic, label the wrong symbols that are there, then tag the error kind. The model learns to read what a child wrote, not what the child should have written.

Row index

The horizontal line a symbol sits on, counted from the top starting at 0. The top operand is row 0, the next operand row 1, and so on. The result under the result bar is its own row below the operands. In long division and multi-row multiplication, each partial-product line and each subtraction step is its own row. A carry or a borrow shares the row of the digits it is written above (it does not get a row of its own).

Column index

The vertical place-value column a symbol sits in, counted from the left starting at 0. The units column is the rightmost column, tens to its left, then hundreds, and so on. Digits that line up vertically (units under units, tens under tens) share the same column index. An operator sits in its own column to the left of the operands.

Equation idx

Which equation the symbol belongs to, starting at 0. There is almost always a single equation per scene here, so leave this at 0 unless a scene clearly holds two separate equations side by side.

When it is an error (and when it is not)

Most scenes are normal correct or partial equations: draw and label them as they are, and leave the error kind on (none).

When the scene asks you to draw a deliberate mistake (the warning banner above the canvas), draw the wrong maths on purpose, fix the boxes so the labels match exactly what you drew, then pick the error kind that describes the mistake: a wrong operator, a wrong result, a wrong digit, or a wrong, extra, or missing carry or borrow.

If a scene you are drawing contains a mistake, still label every box as the wrong symbol you actually drew. Do not fix the digits or the operator to make the answer correct; the as-drawn labels are the ground truth the model is trained on.

When unsure

Label exactly what is on the canvas, never the corrected maths. If a glyph is messy or ambiguous, pick the closest digit it most looks like. If a detected box is the wrong shape or in the wrong place, fix it by dragging or resizing, or delete it and add a new one. A box stays flagged (orange) until you confirm or correct its label, so clear every flag before saving.
